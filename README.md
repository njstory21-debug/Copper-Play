# Copper Play — มื้อนี้มีแพลน

เว็บกิจกรรมเลือกเมนู Copper โทนครีม–คอปเปอร์ สำหรับมือถือและคอมพิวเตอร์

## เปิดใช้ทันที

ดับเบิลคลิก `index.html` ในโฟลเดอร์นี้ด้วย Chrome หรือ Edge ได้เลย ไม่ต้องติดตั้งโปรแกรมเสริมหรือใส่ API key

## อัปโหลดเข้า GitHub Pages

1. แตกไฟล์ ZIP แล้วเปิดโฟลเดอร์ `copper-play`
2. สร้าง repository ใหม่ใน GitHub เช่น `copper-play`
3. เลือก **Add file → Upload files** แล้วลาก **ไฟล์และโฟลเดอร์ทั้งหมดที่อยู่ภายใน copper-play** ลงไป ให้ `index.html` อยู่หน้าแรกของ repository (ไม่ซ้อนในโฟลเดอร์อีกชั้น)
4. กด **Commit changes**
5. ไปที่ **Settings → Pages** เลือก **Deploy from a branch**
6. เลือก branch `main` และโฟลเดอร์ `/(root)` แล้วกด **Save**
7. รอ GitHub เตรียมเว็บ จากนั้นเปิดลิงก์ที่หน้า Pages แสดง

คู่มือ GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

ไม่ต้องใช้ npm ไม่ต้อง build และไม่ต้องแก้เส้นทางไฟล์สำหรับ repository ย่อย

## วิธีเล่น

1. ใส่ชื่อเล่นและวันที่ไปกิน
2. เลือกหมวดอาหารหรือค้นหาชื่อเมนู
3. กด + / − หรือกรอกจำนวน 0–99 ของแต่ละรายการ
4. ปุ่มสุ่มจะเพิ่มหนึ่งเมนูที่ยังไม่ได้เลือกจากหมวดปัจจุบัน
5. กด “สร้างการ์ดสรุป A4” แล้วดาวน์โหลด PNG

ภาพมีขนาด **2480 × 3508 พิกเซล** อัตราส่วน A4 แนวตั้ง เหมาะสำหรับพิมพ์ A4 ที่ประมาณ 300 dpi เลือกขนาดกระดาษ A4 ในโปรแกรมพิมพ์ภาพ ภาพ PNG ใช้ความละเอียดพิกเซลเป็นหลักและไม่ได้ฝังค่า DPI

การ์ดรวมชื่อเล่น วันที่ ชื่อเมนู จำนวนต่อรายการ จำนวนเมนู และจำนวนจาน/ที่รวมไว้ในภาพเดียว รายการจำนวนมากจะจัดเป็น 2 หรือ 3 คอลัมน์อัตโนมัติ

บนมือถือมีแถบสรุปด้านล่างจอ และสามารถแตะภาพค้างเพื่อบันทึกได้หากเบราว์เซอร์ไม่ดาวน์โหลดโดยตรง

## ข้อมูลและการแก้ไข

- มี 103 รายการใน 12 หมวด อ้างอิงเล่ม **The Sense Menu NOV 2026** ที่ผู้ใช้ส่งมา
- ต้นฉบับ: https://online.fliphtml5.com/imgdc/uhyk/#p=1
- ชื่อบางรายการย่อให้อ่านง่าย แต่มีลิงก์ไปหน้าต้นฉบับทุกจาน
- เมนูสถานีใช้รหัส S01–S41 เพื่อจัดการข้อมูลภายในเว็บ รหัสเหล่านี้ไม่ใช่รหัสสั่งอาหารของร้าน
- ไอศกรีมและสลัดบาร์รวมเป็นรายการสถานี เลือกรส/ส่วนผสมจริงที่ร้าน
- `menu.js` เก็บชื่อ หมวด หน้าอ้างอิง และตำแหน่งภาพอาหาร
- `style.css` ใช้ปรับสี รูปแบบ และหน้าจอมือถือ
- `app.js` ใช้ปรับการเลือกเมนูและภาพสรุป A4
- รูปอาหารรวมใน `assets/menu-1.webp` และ `assets/menu-2.webp` เพื่อให้โหลดเร็วและอัปโหลดง่าย หากเปลี่ยนภาพควรจัดตำแหน่งให้ตรงกับ `position` ของเมนู

ข้อมูลชื่อเล่นและรายการที่เลือกบันทึกใน localStorage เฉพาะเบราว์เซอร์/อุปกรณ์นั้น ไม่มีบัญชีผู้ใช้ ฐานข้อมูล หรือการส่งข้อมูลไปเซิร์ฟเวอร์ ฟอนต์และรูปภาพอยู่ในโฟลเดอร์นี้ทั้งหมด จึงไม่มีการเรียก Google Fonts ขณะใช้งาน
